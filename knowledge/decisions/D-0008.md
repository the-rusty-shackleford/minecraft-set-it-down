# D-0008 — Armour measured per item and components

**The ask.** Survivalist Armor (nfx's spec, §11.2; its plan, item 5): a kitted piece of armour set
down must rest on the surface like any other.

**Why.** Survivalist Armor's kits are one data component on the piece; the item is unchanged. A kit
draws the piece much bulkier than the game's armour (straps, plates, pouches standing off it).
`BoundsCache.armour` kept one measured box per `Item`, so a kitted iron chestplate set down after a
plain one took the plain one's box and sank into the table, and a plain one after a kitted one
floated.

**Decision.** The armour box is kept per item and `ItemStack.hashItemAndComponents`, as an item's
box already is per its own model and components (D-0005). A piece seen with new components (a kit,
a trim, a dye, wear) is measured once, by the same one render into nothing, and drawn from the
cache after that.

**Alternatives rejected.**

- *Key on Survivalist Armor's component alone.* Set It Down would have to know another mod's
  component, and any other mod that reshapes armour by component would hit the same bug.
- *Measure every frame.* A display is drawn as cheaply as an item frame because it is measured once.

**Cost.** One measurement per distinct piece per resource reload: a few dozen in a busy world, each
one render of a stand into a capturing buffer.
